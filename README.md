# Transverse

[Play Transverse](https://yrxxxxxxxx1007.github.io/transverse/) on GitHub Pages. Start in training camp and explore the three original expeditions, with English and Simplified Chinese interfaces.

The game runs in the browser with no account or server API. Progress and language preference are saved in the current browser. Players can download their JSON play record from the game menu or results. To preview changes locally, serve this directory with any static file server.
